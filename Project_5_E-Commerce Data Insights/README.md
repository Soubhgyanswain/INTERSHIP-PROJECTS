# 🛍️ E-Commerce Performance Dashboard

This project presents an interactive **E-Commerce Analytics Dashboard** developed during my **Tamizhan Skills Rise Internship**. The dashboard enables users to explore sales, profits, and customer behavior for an e-commerce business, providing powerful insights through dynamic charts and visualizations.

---

## 📝 Project Overview

The goal of this project is to help business users:

- Analyze sales and profit trends over time.
- Identify high-performing product categories and sub-categories.
- Examine customer segments and their profitability.
- Explore sales geographically across U.S. states.

The dashboard was built using **Streamlit** and **Plotly** for a highly interactive, web-based data analysis experience.

---

## 🔧 Tools & Libraries

- Python
- Streamlit
- Pandas
- Plotly Express
- Plotly Graph Objects

---

## Key Features & Visualizations

- Uploads and processes Superstore e-commerce sales data.
- Filters dashboard views by:
  - Year
  - Product Category
  - Customer Segment
  - Date range
- Displays overall KPIs:
  - Total Sales
  - Total Profit
  - Profit Margin
- Sales analysis visualizations:
  - Monthly sales trends
  - Sales distribution by category and sub-category
- Profit analysis visualizations:
  - Monthly profit trends
  - Profit distribution by category and sub-category
- Customer segment analysis:
  - Sales vs. Profit across segments
  - Sales-to-profit ratio by segment
- Geospatial analysis:
  - Choropleth map of sales by U.S. state
- Allows users to:
  - Download filtered datasets
  - View raw data table

---

## How to Run

1. Clone this repository.

2. Install required Python libraries:

    ```bash
    pip install streamlit pandas plotly
    ```

3. Run the Streamlit app:

    ```bash
    streamlit run app.py
    ```

4. Open your browser and navigate to the displayed local URL (usually `http://localhost:8501`).

> **Note:** The dataset file is already included in this repository.
