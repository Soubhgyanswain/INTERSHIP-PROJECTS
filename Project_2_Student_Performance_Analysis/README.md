
# 🎓 Student Performance Analysis Dashboard

This project presents an interactive **Student Performance Analysis Dashboard** developed during my **Tamizhan Skills Rise Internship**. The dashboard empowers users to explore and analyze student performance data through dynamic filters and insightful visualizations.

---

## 📝 Project Overview

The aim of this project is to analyze students’ scores in various subjects and identify patterns across demographic segments such as gender, ethnicity, and test preparation.

Key capabilities of the dashboard include:

- Filtering student records based on demographics and test preparation.
- Visualizing average scores by different groups.
- Exploring correlations between Math, Reading, and Writing scores.

The dashboard was developed in **Streamlit** for web-based interactivity, and a complementary Power BI report offers additional visual exploration.

## Key Features & Visualizations

✅ **Data Upload**  
- Upload student performance data via an Excel file.

✅ **Filters**  
- Filter data by:
  - Gender
  - Ethnicity
  - Test Preparation status

✅ **Summary Statistics**  
- View descriptive statistics for filtered datasets.

✅ **Visualizations**  
- Average scores by Gender
- Average scores by Test Preparation
- Correlation Heatmap for academic scores

✅ **Power BI Report**  
- Additional interactive visuals provided via Power BI (PBIX file included in repo).
