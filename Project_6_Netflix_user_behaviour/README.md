# 🎬 Netflix User Behaviour Dashboard

This project presents an interactive **Netflix User Behaviour Dashboard** developed during my **Tamizhan Skills Rise Internship**. The dashboard provides in-depth analysis of user demographics, viewing preferences, and engagement patterns for Netflix users.

---

## 📝 Project Overview

The objective of this project is to:

- Understand Netflix user demographics and content preferences.
- Visualize user behavior patterns such as time spent on Netflix and genre popularity.
- Enable business stakeholders to gain actionable insights for marketing and content strategies.

The dashboard is built with **Streamlit** and advanced data visualizations using **Plotly** and **Seaborn**.

---

## 🔧 Tools & Libraries

- Python
- Streamlit
- Pandas
- Plotly Express
- Seaborn
- Matplotlib

---

## Key Features & Visualizations

- Upload and analyze Netflix user data from Excel files.
- Apply filters on:
  - Country
  - Gender
  - Genre
- Download filtered datasets as CSV for further analysis.
- Display core metrics:
  - Total Users
  - Average Age
  - Average Weekly Time Spent on Netflix
- Interactive charts and insights:
  - Top 10 countries by user count
  - Gender distribution
  - Scatter plot showing relationship between age and time spent on Netflix, segmented by gender
  - Heatmap illustrating genre preferences across genders
  - Correlation heatmap of numeric variables for deeper analysis of user behavior patterns

---

## How to Run

1. Clone this repository.

2. Install required Python libraries:

    ```bash
    pip install streamlit pandas plotly seaborn matplotlib openpyxl
    ```

3. Run the Streamlit app:

    ```bash
    streamlit run app.py
    ```

4. Open your browser and navigate to the displayed local URL (usually `http://localhost:8501`).

> **Note:** Dataset files are already included in this repository.
