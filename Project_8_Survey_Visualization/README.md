# 📊 Survey Data Visualization Dashboard

This project presents an interactive **Survey Data Visualization Dashboard** developed during my **Tamizhan Skills Rise Internship**. The dashboard allows users to explore survey results and derive insights through filtering and dynamic charts.

---

## 📝 Project Overview

The goal of this project was to create a visual analytics platform where users can:

- Explore survey demographics (gender, age).
- Analyze platform preferences among different groups.
- Visualize relationships between numerical survey attributes.
- Interactively filter and drill down into survey data.

The dashboard was built using **Streamlit**, providing an accessible web-based interface for both technical and non-technical users.

---

## 🔧 Tools & Libraries

- Python
- Streamlit
- Pandas
- Seaborn
- Matplotlib

---

## Key Features & Visualizations

✅ **Show Raw Data**  
- Displays the raw survey dataset for transparency.

✅ **Sidebar Filters**  
- Filter survey data by:
  - Gender
  - Age range

✅ **Preferred Platform Distribution**  
- Count plot showing distribution of preferred platforms.

✅ **Age Distribution**  
- Histogram with KDE curve to visualize age demographics.

✅ **Gender vs Platform Preference**  
- Grouped bar chart to analyze platform choices across genders.

✅ **Correlation Heatmap**  
- Heatmap illustrating correlations between numeric survey variables.

---

##  How to Run

1. Clone this repository.

2. Ensure all required libraries are installed:

    ```bash
    pip install streamlit pandas matplotlib seaborn
    ```

3. Run the Streamlit app:

    ```bash
    streamlit run app.py
    ```

4. Open your browser and navigate to the displayed local URL (usually `http://localhost:8501`).

> **Note:** Dataset files are already included in this repository.
