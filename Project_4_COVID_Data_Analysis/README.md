# 🌍 COVID-19 Country-wise Data Analysis

This project is an interactive **COVID-19 Country-wise Data Analysis Dashboard** developed during my **Tamizhan Skills Rise Internship**. The dashboard visualizes the global spread of COVID-19, helping users explore confirmed cases, deaths, recoveries, and active cases through insightful charts and metrics.

---

## 📝 Project Overview

The aim of this project is to provide a user-friendly interface for:

- Monitoring country-level COVID-19 statistics.
- Comparing regions based on case counts and fatalities.
- Analyzing relationships between key pandemic metrics.

The dashboard was built using **Streamlit** for seamless web deployment and interactivity.

---

## 🔧 Tools & Libraries

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

---

## Key Features & Visualizations

- Display of global summary metrics (confirmed, deaths, recovered, active).
- View raw dataset for transparency and data understanding.
- Top 10 countries ranked by confirmed cases using bar charts.
- Pie chart representing death share among the top 5 countries.
- Scatter plot showing the relationship between recovered and active cases, grouped by WHO region.
- Correlation heatmap between confirmed, deaths, recovered, and active cases.
- Region-wise confirmed cases chart for WHO regions.

---

## How to Run

1. Clone this repository.

2. Install required Python libraries:

    ```bash
    pip install streamlit pandas matplotlib seaborn
    ```

3. Run the Streamlit app:

    ```bash
    streamlit run app.py
    ```

4. Open your browser and navigate to the displayed local URL (usually `http://localhost:8501`).

> **Note:** Dataset files are already included in this repository.
